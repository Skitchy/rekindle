# Rekindle Brand SVG Assets

These are hand-built SVG recreations of the Rekindle continuity logo: the flame + circuit + circular-arrow mark, the REKINDLE MCP wordmark, and the tagline “Capture Today. Remember Tomorrow.”

## Files

- `rekindle-logo-hero.svg` — dark, mockup-style hero/header version.
- `rekindle-logo-horizontal.svg` — transparent horizontal logo for website/GitHub headers.
- `rekindle-mark.svg` — standalone Rekindle continuity mark.
- `rekindle-favicon.svg` — simplified square favicon/app icon starter.
- `rekindle-social-card.svg` — 1200×630 social preview card.

## Important note

These are vector recreations, not automatic traces of the raster mockup. That is intentional: production SVGs should stay cleaner than the glowing mockup so they remain useful at small sizes.

## Font note

The SVGs use live text with fallback font families such as `Orbitron`, `Eurostile`, `Bank Gothic`, `Montserrat`, and `Arial`. The exact appearance will vary depending on installed fonts. For final production, either:

1. choose a web font and load it on the site, or
2. convert the text to outlines in Inkscape, Figma, or Illustrator.

Do not redistribute proprietary font files.
